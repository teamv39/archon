# Pricing: тарифы и токен-лимиты Managed SaaS

> **Статус:** черновик для обсуждения (ARCH-30) · 2026-11-07
> **Что здесь решено, а что нет:** структура тарифов и логика лимитов — предложение. Все цифры в таблицах — рабочие гипотезы, не решение. Решение принимает лид после обсуждения.
> **Чего ждём:** публичные цены конкурентов нужно перепроверить (кластер C в [desk-research-report.md](desk-research-report.md), ARCH-29), токены на репозиторий — из бенчмарка ARCH-36.

Модель поставки — Managed SaaS ([ADR-0006](../adr/0006-saas-delivery-model-and-ai-native-source-of-truth.md)). Биллинг и квотирование токенов LLM живут в модуле `platform` ([tech-stack.md](../architecture/tech-stack.md)).

## 1. Что тарифицируем

| Вариант единицы | Плюсы | Минусы |
| :--- | :--- | :--- |
| Место (seat) | Понятно покупателю, привычно по Port и OpsLevel | Слабо связано с нашей себестоимостью (она зависит от размера репо, а не от числа людей) |
| Репозиторий / сервис | Ближе к себестоимости | Непривычно, трудно прогнозировать счёт |
| Токены LLM | Честно по затратам | Покупатель не понимает, сколько ему нужно |

**Предложение:** гибрид. Основа цены — место (как у рынка, легко сравнить). Себестоимость защищаем лимитами: число подключённых репозиториев и месячный пул токенов на организацию. Превышение пула — докупка пакетами, а не отключение.

## 2. Предлагаемые тарифы

| | Free | Team | Enterprise |
| :--- | :--- | :--- | :--- |
| Цена | 0 | рабочая гипотеза $30 за место в месяц | от $50 за место в месяц, по договору |
| Места | до 5 | от 5 | без ограничений |
| Репозитории | 1 | до 20 (докупаются) | по договору |
| Пул токенов LLM в месяц | малый, задаёт ARCH-36 | на организацию, масштабируется с местами | по договору |
| Граф архитектуры, портал | да, только чтение | да | да |
| MCP-сервер для IDE | да, с лимитом запросов | да | да |
| PR-бот и гейты | нет | да | да |
| Assurance и политики | нет | да | да |
| SSO (OIDC/SAML), аудит, RBAC | нет | нет | да |
| Выделенный контур (VPC), закрытые контуры | нет | нет | отдельное предложение, зависит от OQ-23 |
| Поддержка | сообщество | стандартная | SLA |

Free нужен как путь к быстрой победе (Time-to-Value в минутах, см. [business-value-analysis.md](business-value-analysis.md)). Ценовой пол задаёт Port: бесплатно до 15 человек. Мы такой щедрости не можем себе позволить из-за LLM, поэтому Free ограничен одним репозиторием.

## 3. Токен-лимиты: логика расчёта

Конкретные числа дадим после ARCH-36 (токеномика извлечения) и пересчёта M1. Порядок расчёта:

1. Целевая себестоимость на место: доля от цены (гипотеза: не более 30% от $30, то есть около $9).
2. Из неё доля на LLM (interpret + drift). Остальное — инфраструктура и поддержка.
3. Бюджет LLM на организацию = число мест × доля на LLM.
4. Пул токенов = бюджет / средняя цена токена выбранной модели.
5. Проверка: хватает ли пула на ежедневный прогон типового репозитория (из ARCH-36).

Рычаги снижения затрат, уже заложенные в архитектуру: детерминированный `extract` без LLM, кэширование графа и MCP-ответов, LLM только для семантики доков ([ADR-0006](../adr/0006-saas-delivery-model-and-ai-native-source-of-truth.md)).

Что лимитируем и почему:

| Лимит | Зачем |
| :--- | :--- |
| Токены на организацию в месяц | Главный драйвер себестоимости |
| Число репозиториев | Грубая защита от аномально больших клиентов |
| Запросы MCP в минуту | Защита от злоупотреблений; сами ответы дешёвые благодаря кэшу |
| Частота полного пересчёта графа | Полный прогон дороже инкрементального (OQ-6) |

## 4. Проверка экономики (по существующим данным)

Данные из [business-value-analysis.md](business-value-analysis.md), раздел 5, ещё не перепроверены:

| Показатель | Значение |
| :--- | :--- |
| Выручка, Team 50 мест по $30 | $1 500 в месяц |
| Себестоимость SaaS (гибридная архитектура) | $500-700 в месяц |
| Валовая маржа | 53-67% при $30 (считаю сам), 70-75% при $40-50 (заявлено в анализе) |
| Потенциальная экономия клиента | $100K-200K в год (гипотеза H-C3) |

Расчёт: при $30 за место и себестоимости $500-700 на 50 мест маржа получается ниже заявленных 70-75%. Либо цена выше, либо себестоимость ниже. Проверяем после ARCH-36.

## 5. Открытые вопросы (решает лид)

1. **Единица тарификации.** Место, репозиторий или гибрид, как предложено выше?
2. **Цена Team.** $30 или $40-50? В [business-value-analysis.md](business-value-analysis.md) разделы 3 и 5 расходятся ($25-35 против $40-50). Нужно выбрать один якорь.
3. **Размер Free.** Один репозиторий и 5 мест достаточно для быстрой победы или это слишком мало?
4. **Публиковать ли цену Enterprise.** Конкуренты скрывают, мы можем показать вилку.
5. **Закрытые контуры.** Продаём ли как Enterprise-надстройку до решения OQ-23?
6. **Что делать при исчерпании пула.** Отключать LLM-функции, замедлять или докупать пакетами?

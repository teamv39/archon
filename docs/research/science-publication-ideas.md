# Идеи для научных публикаций по Archon

> **Раздел:** `docs/research/`  
> **Статус:** Черновик (Идеи для статей / R&D)  
> **Связанные документы:** [RFC гибридного анализа](../architecture/rfc-hybrid-repository-analysis.md), [Extraction Contract v1.0](../architecture/contracts/README.md), [ADR-0003](../adr/0003-source-of-truth-and-tenant-isolation.md)

Тезисы и исследовательские направления для академических и отраслевых публикаций на основе технологий Archon:

## 1. Угол A: Knowledge Graph Extraction Pipeline
- **Тема:** Гибридный контур извлечения архитектурного графа (Hybrid AST + LLM extraction) с правилом Proof-of-Truth.
- **Ключевой результат / Метрика:** Снижение расхода токенов на 90% при сохранении 100% верифицируемости архитектурных связей по `evidence_files`.
- **Бенчмарк:** Тестирование обхода графа на 50 клиентских схемах с задержкой <15ms traversal.

## 2. Угол B: MCP-Based Architecture Context for AI Agents
- **Тема:** Граф знаний как Source of Truth для AI-агентов разработчика (Cursor, Copilot, Claude Code).
- **Ключевой результат:** Граундинг агента через структурный граф зависимостей вместо стохастического RAG/векторного поиска.
- **Сценарии:** Предотвращение архитектурного дрейфа и валидация зависимостей при генерации кода через запросы Impact Analysis.

## 3. Угол C: Multi-Tenant Graph Storage на базе PostgreSQL + Apache AGE
- **Тема:** Модель изоляции Graph-per-Tenant в гибридной реляционно-графовой СУБД.
- **Ключевой результат:** Экономическая эффективность и строгая изоляция данных тенантов в enterprise SaaS без оверхеда на управление отдельными графовыми кластерами.
- **Бенчмарк масштабирования:** Сравнение производительности Cypher-запросов (поиск циклов и расчет blast radius) при росте числа изолированных схем.

## Общие стандарты и дизайн-система

### 1. Инженерный стиль (High-Density DevTools)
Интерфейс строится по эталонам современных B2B-систем для разработчиков (Linear, Datadog, Vercel, GitHub).
* Компактные отступы, максимальная информативность на одном экране без лишнего скролла.
* Отсутствие декоративных элементов, отвлекающих от данных.

### 2. Цветовая палитра (Dark Mode First)
* **Фон страницы:** `zinc-950` (`#09090b`).
* **Карточки и панели:** `zinc-900` (`#18181b`).
* **Разделители и границы:** `zinc-800` (`#27272a`).
* **Основной текст:** `zinc-100` (`#f4f4f5`).
* **Второстепенный текст и подписи:** `zinc-400` (`#a1a1aa`).

### 3. Семантика цвета статусов
Цвет используется строго функционально:
* **Зеленый (`emerald`):** `In Sync` / `Zero Drift` — документация полностью соответствует коду.
* **Красный (`rose` / `red`):** `Drift Detected` / `Critical` — зафиксировано расхождение или архитектурная ошибка.
* **Желтый (`amber`):** `Risk Accepted` — временное отклонение от архитектурных правил согласовано.
* **Фиолетовый/Синий (`indigo`):** системные ссылки, теги технологий и навигационные элементы.

### 4. Типографика
* **Интерфейс:** Inter или Geist Sans (13–14px базовый размер для высокой плотности).
* **Код и координаты:** JetBrains Mono или Geist Mono (пути к файлам, Git SHA, номера строк, схемы DTO).

## Глобальная оболочка приложения (App Shell)

Все экраны работают внутри единого лейаута:

```
┌────────────────────────────────────────────────────────────────────────┐
│ ┌───────────────┐ ┌──────────────────────────────────────────────────┐ │
│ │ Archon [Org]  │ │ [Поиск: Cmd+K]                       [Sync] [User]│ │ Top Bar
│ ├───────────────┤ ├──────────────────────────────────────────────────┤ │
│ │ • Каталог     │ │                                                  │ │
│ │ • Карта C4    │ │                                                  │ │
│ │ • Инбокс [3]  │ │                 Контентная область                │ │
│ ├───────────────┤ │                                                  │ │
│ │ v1.0 • Docs   │ │                                                  │ │
│ └───────────────┘ └──────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────┘
```

* **Левый сайдбар:** Логотип Archon, селектор организации, пункты меню («Каталог сервисов», «Архитектурная карта», «Инбокс находок» со счетчиком), статус синхронизации репозиториев, профиль.
* **Верхняя панель:** Командная строка `Cmd+K` для быстрого перехода к любому сервису, эндпоинту или находке; индикатор свежести данных графа.

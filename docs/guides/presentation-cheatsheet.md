# Шпаргалка для презентации Archon

## 30 секунд

Archon — платформа, где архитектура не рисуется, а **собирается из кода и доков**. Миссия — Zero Drift: найти, где доки врут, и не дать смержить PR, пока не исправлено. Сейчас это не делает никто.

## Что видит пользователь (4 точки входа)

Шестнадцать модулей — это фабрика. Пользователь видит только витрину:

- **портал** — карта C4, каталог сервисов, инбокс находок, зрелость;
- **PR-бот** — коммент/гейт в MR: "этот PR дрейфует `docs/payments.md`";
- **чат-бот** — ответ из графа с provenance (узел + строка кода);
- **экспорт** — срез на дату для аудита вместо скриншотов.

Всё остальное — невидимые блоки за ними. Подробнее — `architecture/product-overview.md`.

## 5 блоков (так рассказывать, а не слоями)

Слои конвейера технически верны, но для презентации группируй по близости к пользователю:

| Блок | Модули | Фраза |
| :--- | :--- | :--- |
| Витрина | portal, pr-bot, chat-bot, export | показать там, где человек уже работает |
| Решение | assurance | находка живёт `обнаружена -> исправлена / риск принят / ложня` |
| Мозг | model, resolve, policies, drift | единый граф + что не так |
| Фабрика | registry, sources, extract, interpret, reconcile | копать факты и решать, кто прав |
| Фундамент | runtime, platform | очереди, бюджеты LLM, SSO/права/аудит |

MVP: витрина = portal + pr-bot, герой-фича — drift ("доки врут — вот пруф").

## Поток (если спросят "как устроено")

`registry -> sources -> extract/interpret -> reconcile -> model -> resolve -> policies/drift -> assurance -> каналы`. `runtime`/`platform` — горизонтальные слои. Диаграмма — в `modules/README.md`.

## Что поменяла ревизия 1 (ADR-0004)

Было 10 модулей с буквами → стало 16 плоских. Три смысла: `reconcile` отдельно (конфликты), `registry/sources` разделены (что анализировать vs как дотянуться), `assurance` — единый контур решения.

## Рынок — одна фраза

- **Backstage** — стандарт каталога, но не знает про drift; фреймворк, требует команду.
- **Port/OpsLevel** — SaaS-скоркарды, drift = несоответствие проверке, не доки-код. Нет on-prem.
- **Compass** — лёгкий каталог Atlassian, вне Atlassian ценность падает.
- **Structurizr/IcePanel** — лучшие C4, но это картинка, не граф фактов.
- **Swimm** — ближайший по "docs drift", но уровень сниппета, не архитектуры.

Вывод: мы не "ещё каталог". Мы замыкаем `код+доки -> граф -> drift -> решение -> PR-гейт`.

## Q&A

**"Почему не плагин к Backstage?"** Наша ценность — `extract/interpret/reconcile/drift`, вычислительное ядро. Portal совместим с catalog-info — надстраиваемся, не конкурируем.

**"Зачем interpret отдельно?"** extract — точно/дешево, interpret — смысл/дорого. Смешать — не отличить факт от догадки.

**"Кто owns модуль?"** Никто (ADR-0004). Владение — свойство задачи.

**"Когда код?"** После OQ-1/2/8.

# `pr-bot` — архитектурный diff в MR

Статус: new
Зависит от: model, extract (инкрементальный), interpret (инкрементальный), assurance
Используется: — (терминальный канал)

## Назначение

Подсвечивает архитектурные последствия pull request'а там, где автор его и
увидит: прямо в Merge Request. Без этого качество архитектуры — вопрос
личного внимания ревьюера.

## Что делает

- На diff PR'а (а не всего репо) прогоняет инкрементальный контур извлечения
  и строит архитектурный diff через `model`.
- Комментирует в MR: "добавлен доступ к чужой БД", "появился цикл
  зависимостей", "новый недокументированный контракт" — со ссылкой на
  дашборд и с объяснением "кто это сказал" (provenance из `reconcile`).

Степень интеграции не выбрана: комментарий, GitHub Checks, GitLab widget,
статус-чек, влияющий на автокат PR.

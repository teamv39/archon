# `extract` — извлекает факты из кода (разбор синтаксиса, без языковой модели)

Статус: new
Компетенция: компиляторы, парсеры, манифесты, языки
Зависит от: sources, registry
Используется: reconcile, model (косвенно), resolve

## Назначение

Вытаскивает из кода факты, которые можно назвать однозначно: вызовы между сервисами, контракты API (описания по стандартам), подключения к базам данных, зависимости из файлов сборки. Делает это дёшево и детерминированно — без домыслов и галлюцинаций. Поэтому на его выводах надёжно держатся и проверка правил (`policies`), и склейка сущностей (`resolve`).

До пересмотра декомпозиции жил одной половиной большого модуля извлечения — вместе с контуром на языковой модели. При разборе декомпозиции выяснилось: у этих половин разные владельцы, разная стоимость, разные причины сбоев и разная скорость изменений. Это два модуля, а не один.

## Что делает

- Разбирает код на структурном уровне (деревья синтаксиса) и читает манифесты: файлы сборки, описания окружений, спецификации API.
- Приводит извлечённое к записям-фактам — фрагментам будущего контракта извлечения (единого формата передачи фактов).
- Для каждого факта сообщает: «вот точный факт и его координаты в коде, за него ручаемся».

Не делает: не понимает, что компонент «значит» для бизнеса; не решает, что факт означает нарушение; не хранит историю (`model`); не разрешает спор с `interpret` (`reconcile`).

## Интерфейсы

- **Вход:** снимки кода и события от `sources`.
- **Выход:** поток фактов в `reconcile` в формате канонического [Extraction Contract v1.0](../contracts/README.md).

## Данные

Модуль не хранит постоянного состояния: код клонируется во временный RAM-диск (`/dev/shm`), парсится и немедленно удаляется (`rm -rf`) согласно политике Privacy-by-default. В памяти формируется промежуточный каркас Слоя 0.

## Форма деплоя

Сборочная единица **`archon-core-service`** (Kotlin / JVM) согласно [ADR-0007](../../adr/0007-saas-process-topology-and-packaging.md) и [`deployment.md`](../deployment.md). Выполняется как Temporal Activity (`CloneAndExtractAST`). Архитектура Слоя 0 (детерминированный сбор) детально зафиксирована в [RFC гибридного анализа](../rfc-hybrid-repository-analysis.md).

## Открытые вопросы

- OQ-6 (инкрементальный анализ по diff вместо полного сканирования).
- OQ-9 (словарь терминов и тегов).
- OQ-3 закрыт спецификацией [Extraction Contract v1.0](../contracts/README.md).
- OQ-8 закрыт в [ADR-0007](../../adr/0007-saas-process-topology-and-packaging.md).
- OQ-11 закрыт в ADR-0004 (разделение контура извлечения).

## Решения

- ADR-0004 (выделен из бывшего единого модуля извлечения).
- ADR-0007 (упакован в `archon-core-service` как первый шаг пайплайна Temporal).

## Заметки

Именно здесь у факта появляется происхождение — запись «это сказал такой-то парсер такой-то версии». Без неё `reconcile` не сможет разрешать споры источников, а `model` — показывать уровень доверия.

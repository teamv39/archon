# m2. `graph` — Knowledge Graph

Статус: new
Владелец: Денис
Зависит от: m1 (контракты), e2 (для правок и обогащения)
Используется: m3, m4, d1, d2, d3, d4

## Назначение

Персистентная, версионируемая, запросная модель системы — ядро Archon. Без
этого модуля Archon остается генератором картинок. Все остальные модули либо
пишут в граф, либо читают его, ничего не дублируя.

## Что делает

- Хранение узлов и связей (черновая модель: `../data-model.md`).
- Версии и история: "что было на коммит X", diff между версиями графа.
- Query API: impact analysis, поиск, выборки для всех верхних слоев.
- Merge engine: разрешение конфликтов "автогенерация vs ручные правки"
  (человек не должен затираться перезапуском — pain из archmap v3).
- Атрибуты доверия к элементам: `auto` / `reviewed` / `accepted` + provenance
  (кем сказано: AST, LLM, человек).
- Склейка сущностей из разных репозиториев в один узел — открытый вопрос
  (OQ-7), решения нет.

Не делает: не извлекает из кода (`m1`), не интерпретирует правила (`m3`), не
ранжирует документы (`m4`).

## Интерфейсы

- **Вход:** Extraction Contract из `m1`; ручные правки через MR.
- **Выход:** query API для всех потребителей `d1..d4` и `m3/m4`.

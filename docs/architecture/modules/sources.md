# `sources` — коннекторы к внешним системам (как подключиться к Git, Jira, Confluence)

Статус: spec
Компетенция: интеграции, API провайдеров (Git/Jira/Confluence)
Зависит от: registry (что читать), platform (секреты, RBAC)
Используется: extract, interpret, drift, resolve

## Назначение

Единая точка входа внешних данных: репозитории, Jira, Confluence, мессенджеры.
Остальные модули не ходят в GitHub/GitLab/Bitbucket напрямую разными
способами — в archmap это, например, делается по-своему на каждый прогон.

## Что делает

- Чтение репозиториев (клон / trees API, диффы между коммитами, листинги).
- Приемник webhooks: "репозиторий изменился".
- Коннекторы Jira, Confluence, мессенджеров.
- Отдача **сырых артефактов с метаданными источника**.

Граница по атаке A10: `sources` = транспорт и аутентификация, всегда
возвращает сырье; нормализация в доменную модель — на потребителе (`extract`
и `interpret` для кода, `drift` для документов). Не решает, что данные
означают.

## Интерфейсы

- **Выход** в `extract`/`interpret`: события "репозиторий изменился" +
  снапшот файлов.
- **Выход** в `drift`: поток документов с метаданными.
- Форма событий и артефактов не зафиксирована (OQ-6).

## Данные

Не хранит ничего, кроме cursor/offset для непрерывного чтения. Секреты —
только через `platform`.

# m4. `drift` — детектор рассинхрона документации и кода

Статус: concept
Владелец: Миша
Зависит от: m2, e2 (Confluence/Jira)
Используется: d1, d4

## Назначение

Выполняет главную миссию Archon: документация не должна расходиться с кодом.
Модуль сравнивает утверждения из документов с фактами графа и показывает, где
доки врут.

## Что делает

- Индексация Confluence/ADR/спеков: эмбеддинги + реестр "документ -> элемент
  графа".
- Сравнение claims из документов с фактами графа.
- Алерты "эта страница противоречит коду", сводный индекс дрейфа как метрика
  продукта.

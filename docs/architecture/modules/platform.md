# `platform` — enterprise-обвязка

Статус: new
Зависит от: нет (обслуживает остальные)
Используется: все модули

## Назначение

Отделяет "набор сервисов" от "платформы": с этим модулем продукт можно
продавать в контур enterprise, без — это внутренний скрипт. Управляет тем,
кто что видит, и тем, что ничто не утекает наружу.

## Что делает

- SSO (SAML/OIDC), RBAC — единая модель прав для всех модулей.
- Audit log — особенно решений из `assurance` (для J6/аудита).
- Multi-tenancy: изоляция корпусов клиентов.
- Управление секретами (закрывает проблему PAT-ов в n8n-таблице из
  прототипа).
- Упаковка для on-prem развертывания.

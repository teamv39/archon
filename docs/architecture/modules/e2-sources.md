# e2. `sources` — коннекторы источников

Статус: concept
Владелец: Максим
Зависит от: e1 (RBAC/секреты — когда появятся)
Используется: m1, m4, d3

## Назначение

Единая точка входа внешних данных в Archon: репозитории, Jira, Confluence.
Приводит всё к формату "файлы + метаданные + события", чтобы остальные модули
не ходили в GitHub/GitLab/Bitbucket напрямую разными способами (в archmap это
делается по-своему на каждый прогон).

## Что делает

- Чтение репозиториев (клон / trees API, диффы между коммитами, листинги),
  webhooks-приемник.
- Коннекторы Jira, Confluence — нормализация в общий документ-индекс.

## Интерфейсы

- **Выход** в `m1`: события "репозиторий изменился" + снапшот файлов.
- **Выход** в `m4`: поток документов с метаданными источника.

Форматы пока не зафиксированы (OQ-6).

## Данные

- Секреты наружу не хранит: только через `e1`.

# d4. `chat-bot` — бот помощника в мессенджере

Статус: concept
Владелец: Максим (интеграции) + Миша (RAG)
Зависит от: m2 (граф), m4 (RAG по докам), e2 (мессенджер-коннектор)
Используется: — (терминальный канал)

## Назначение

Дать доступ к Archon изнутри рабочего мессенджера: запустить прогон не уходя
в портал, задать вопрос по системе на естественном языке и получить ответ
из графа и документов.

## Что делает

- Запуск прогонов (наследник TiMe-бота archmap).
- RAG-вопросы по графу и докам (поверх `m4`).

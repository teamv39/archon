# m3. `policies` — движок правил и аномалий

Статус: concept
Владелец: Паша
Зависит от: m2, детерминированная часть m1
Используется: d1, d2

## Назначение

Проверяет граф на архитектурные аномалии. Правила живут как "rules as code":
команды расширяют их без релиза продукта, а возникновение/принятие риска видно
на дашбордах.

## Что делает

- Декларативные правила над графом (резервный список: shared DB, циклы,
  обход gateway, undeclared dependency — окончательный набор не определен).
- Детекты с severity, статусами
  `detected` / `accepted` / `fixed` / `false_positive`, workflow принятия риска
  с обоснованием и сроком.

## Данные

Хранит детекты и их статусы; сам граф не хранит, читает через query API `m2`.

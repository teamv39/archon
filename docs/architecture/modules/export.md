# `export` — выгрузка и отчётность

Статус: new
Зависит от: model, assurance, resolve (landscape)
Используется: — (терминальный канал)

## Назначение

Достаёт результаты наружу в файлово-отчётной форме: аудит для регулятора и
CISO (сценарий J6), периодические отчёты, выгрузка графа/landscape во
внешние системы.

Введён ревизией: дефект F7 — ни один канал старой декомпозиции не описывал
регуляторный экспорт, а для enterprise это не опция.

## Что делает

- Отчёт по находкам и их статусам (что принято в риск, что нет, кем).
- Экспорт фрагментов графа и landscape (форматы TBD).
- Доказательная база аудита: provenance + решения + audit-след из
  `assurance`/`platform`.

Не делает: не хранит правду, не считает — только материализация того, что
есть в `model`/`assurance`.

## Заметки

Отчёт — единственная форма, где несовершенство deep links (F2) почти
безразлично: аудиту нужна выгрузка, а не кликабельность. Это не повод
оставлять F2 открытым — просто экспорт его не маскирует.

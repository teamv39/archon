# `export` — выгрузка, отчётность и генерация docs-as-code

Статус: new
Зависит от: model, assurance, resolve (ландшафт)
Используется: — (терминальный канал)

## Назначение

Достаёт результаты наружу в виде файлов, отчётов и docs-as-code артефактов:
1. Генерация структурированных инструкций и файлов контекста для AI-агентов (`AGENTS.md`, `.archon/`, C4) для синхронизации с Git-репозиториями (Git Sync).
2. Выгрузки для регулятора и службы безопасности, периодические аудиторские отчёты.
3. Экспорт фрагментов графа во внешние системы (LikeC4, JSON).

## Что делает

- **Генерация docs-as-code (ADR-0006, OQ-19):** компилирует актуальное состояние сервиса из графа `model` в понятные AI-агентам файлы (`AGENTS.md`, карточки сервиса), передает их в коннекторы Git для оформления PR или прямого коммита.
- **Аудиторская отчётность:** формирует отчёт по находкам и их статусам: что принято в риск, кем и когда — доказательная база из `assurance` и `platform`.
- **Экспорт архитектурного графа:** сериализация графа и ландшафта во внешние форматы (JSON, Structurizr DSL, LikeC4).

Не делает: не хранит свою копию правды, не считает заново — только материализует то, что уже есть в `model` и `assurance`. Не занимается транспортом в Git напрямую — для этого использует коннекторы `sources`.

## Форма деплоя

Сборочная единица **`archon-core-service`** (Kotlin / JVM) согласно [ADR-0007](../../adr/0007-saas-process-topology-and-packaging.md) и [`deployment.md`](../deployment.md). Выполняется как фоновая активность оркестратора Temporal или вызывается синхронно контроллером REST API при запросе экспорта LikeC4 DSL / документов.

## Открытые вопросы

- Форматы выгрузки и требования регуляторного аудита.
- Формат и структура генерируемого `.archon/` каталога в репозиториях.
- OQ-8 закрыт в [ADR-0007](../../adr/0007-saas-process-topology-and-packaging.md).

## Решения

- ADR-0004 (создание модуля для регуляторного экспорта).
- ADR-0006 и OQ-19 (передача модулю функций генератора docs-as-code для Git Sync).
- ADR-0007 (упаковка движка генерации в `archon-core-service`).

## Заметки

Отчёт — единственная форма, где отсутствие постоянных ссылок на элементы графа почти безразлично: аудиту нужна выгрузка, а не кликабельность. Это не повод оставлять вопрос ссылок открытым — просто экспорт его не маскирует.

# `mcp` — сервер Model Context Protocol для AI-агентов

Статус: new  
Компетенция: сетевые протоколы (MCP, JSON-RPC), интеграция с AI-агентами (Cursor, Copilot, Claude Code)  
Зависит от: model (API запросов к графу), assurance (статусы находок и рисков), policies (правила архитектуры), platform (аутентификация и права)  
Используется: — (терминальный канал)

## Назначение

Обеспечивает прямое подключение AI-агентов (Cursor, Copilot, Claude Code, внутренние агенты) к актуальному архитектурному контексту компании по протоколу Model Context Protocol (MCP). 

Без этого модуля агенты вынуждены угадывать зависимости или сканировать чужие репозитории целиком, сжигая контекстное окно и галлюцинируя. `mcp` превращает Archon в живой Context Layer для агентной разработки (ADLC).

## Что делает

- Реализует серверную спецификацию Model Context Protocol (JSON-RPC поверх HTTP/SSE или stdio).
- Экспортирует **ресурсы (MCP Resources)**:
  - Архитектурная топология сервиса: входящие и исходящие вызовы, слои.
  - Спецификации контрактов: OpenAPI схемы, DTO, Kafka/NATS топики.
  - Архитектурные инварианты и правила (`policies`), запрещающие антипаттерны (прямой доступ в чужую БД, обход шлюзов).
- Предоставляет **инструменты (MCP Tools)**:
  - `get_service_context(service_id)` — получение паспорта и связей сервиса.
  - `find_dependents(service_id, contract_id)` — проверка impact analysis (кто сломается при изменении).
  - `check_compliance(proposed_call)` — проверка допустимости вызова по политикам.
  - `get_finding_status(finding_id)` — проверка принятых компромиссов из `assurance`.
- Предоставляет **промпты (MCP Prompts)**: структурированные системные инструкции для кодогенерации с учетом соглашений проекта.

**Не делает:**
- Не парсит код и не строит граф сам (это делают `extract`, `interpret`, `model`).
- Не хранит код и не исполняет код на стороне агента.
- Не принимает архитектурных решений (это делает человек через `assurance` и портал).

## Интерфейсы

- **Вход:** Query API модуля `model` (доступ к графу связей), API `assurance`, валидация токенов через `platform`.
- **Выход:** клиентам MCP (IDE-агентам) в формате JSON-RPC.

## Данные

Собственного постоянного состояния не хранит. Является тонким транслятором между Knowledge Graph и протоколом MCP. Кэширует частые запросы контекста в памяти (Redis / in-memory).

## Форма деплоя

В соответствии с ADR-0006 — компонент управляемого облака Archon Managed Cloud (SaaS). Доступен клиентам по защищенному HTTPS/SSE эндпоинту с токеном авторизации организации.

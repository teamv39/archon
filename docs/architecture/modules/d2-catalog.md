# d2. `catalog` — Service Catalog / Service Passport

Статус: concept
Владелец: Денис (модель) + frontend
Зависит от: m2 (ядро), m3, m4, e2 (Jira ownership)
Используется: — (терминальный канал)

## Назначение

Сводная карточка сервиса (Passport) и каталог сервисов. Это витрина, собранная
из графа, аномалий, дрейфа и владельцев из Jira.

Важно: Passport — не отдельный модуль-хранилище, а представление над `m2`.
Сделать его вторым источником правды про сервис нельзя — иначе вернется та же
проблема дрейфа, которую продукт решает.

## Что делает

- Карточка сервиса: бизнес-контекст, владельцы, стек, контракты, связи, индекс
  здоровья/дрифта.
- Каталог и поиск по сервисам.

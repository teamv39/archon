# `policies` — ищет архитектурные проблемы в графе

Статус: new
Компетенция: архитектура, правила, анализ графов
Зависит от: model, resolve (склеенный граф)
Используется: assurance, portal

## Назначение

Проверяет граф на архитектурные нарушения. Правила — "rules as code": команды
расширяют их без релиза продукта, а возникновение принимается там же, где
видны все показчики.

## Что делает

- Декларативные правила над графом (резервный список: shared DB, циклы,
  обход gateway, undeclared dependency — окончательный набор не определён).
- Вычисление детектов.
- Не хранит детекты и их статусы — читает граф через query API `model` и
  пишет находки в `assurance`. Статусами, workflow и принятием риска владеет
  `assurance`.

## Данные

Свои правила и их версионирование; остальное в графе/находках не живёт.

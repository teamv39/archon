# d3. `pr-bot` — архитектурный diff в MR

Статус: concept
Владелец: Паша (интеграция с Git) + Денис (логика diff'а)
Зависит от: m2 (запросы к графу), m1 (инкрементальный анализ PR-diff'а — когда появится)
Используется: — (терминальный канал)

## Назначение

Подсвечивает архитектурные последствия pull request'а там, где автор его и
увидит: прямо в Merge Request. Без этого качество архитектуры — вопрос личного
внимания ревьюера.

## Что делает

- На diff PR'а (а не всего репо) прогоняет инкрементальный `m1` и строит
  архитектурный diff через `m2`.
- Комментирует в MR: "добавлен доступ к чужой БД", "появился цикл зависимостей",
  "новый недокументированный контракт" — с ссылкой на дашборд.

Другая степень интеграции не выбрана — может быть GitHub Checks, GitLab MR
widget, статус-чек, меняющий автокат PR.

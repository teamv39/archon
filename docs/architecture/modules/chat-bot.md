# `chat-bot` — помощник в мессенджере

Статус: new
Зависит от: model, assurance (ответы по графу и документам), sources (связь с мессенджером)
Используется: — (терминальный канал)

## Назначение

Доступ к Archon из рабочего мессенджера: запустить проверку, не открывая портал, и спросить по-человечески про систему, получив ответ из графа и документов.

## Что делает

- Запускает прогоны анализа (через `runtime`; развитая идея чат-бота из прототипа).
- Отвечает на вопросы о системе на естественном языке: ищет по графу и документам с помощью индексов `drift`.
- Даёт короткий ответ с ссылкой на точное место в портале вместо пересказа — со ссылкой можно перейти и посмотреть всё самому. Сейчас таких постоянных ссылок на элемент графа нет; это известная прореха в `model`.

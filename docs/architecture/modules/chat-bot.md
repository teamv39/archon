# `chat-bot` — помощник в мессенджере

Статус: new
Зависит от: model, assurance (RAG-ответы по графу/докам), sources (транспорт мессенджера)
Используется: — (терминальный канал)

## Назначение

Доступ к Archon изнутри рабочего мессенджера: запустить прогон, не уходя в
портал, и спросить по-человечески про систему, получив ответ из графа и
документов.

## Что делает

- Запуск прогонов (через `runtime`; наследник TiMe-бота archmap).
- Вопросы по системе на естественном языке: RAG по графу и документам
  (инфраструктура `drift`).
- Короткие ответы с deep link в `portal` вместо пересказа (требование F2).

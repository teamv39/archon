# `model` — хранит граф связей о системе

Статус: blocked (OQ-2)
Зависит от: reconcile
Используется: resolve, policies, drift, assurance, portal, pr-bot, chat-bot, export

## Назначение

Персистентная, версионируемая, запросная модель системы — ядро Archon. Без
этого модуля Archon остается генератором картинок. Все остальные модули либо
пишут в граф, либо читают его, ничего не дублируя.

## Что делает

- Хранение узлов и связей (черновая модель: `../data-model.md`).
- Версии и история: "что было на коммит X", diff между версиями графа.
- Query API: impact analysis, поиск, выборки для всех верхних слоев.
  Требование A9: единый мультимодальный контракт для всех каналов доставки
  (структура + текст + короткая ссылка) — если API не выдержит четыре
  канала, API плохой.
- Stable deep link на элемент графа (дефект F2) — требование к API.
- Merge engine: разрешение конфликтов "автогенерация vs ручные правки"
  (человек не должен затираться перезапуском — pain из archmap v3).

Не делает: не извлекает из кода (`extract`/`interpret`), не примиряет
(`reconcile`), не склеивает сущности между репо (`resolve`), не
интерпретирует правила (`policies`), не ранжирует документы (`drift`), не
ведёт ревью (`assurance`).

## Интерфейсы

- **Вход:** разрешённые факты из `reconcile`; ручные правки через MR;
  trust-статы из `assurance`.
- **Выход:** query API для всех потребителей.

## Данные

Здесь главный вопрос продукта (OQ-2): где source of truth — git-файлы,
граф-БД или гибрид (git как декларативный truth, БД как производный индекс).
До решения все остальные пункты подвешены: выбор движка (OQ-5), схема,
merge-стратегия. **Модуль не кодить до решения OQ-2** (вердикт A1: ядро —
самый хрупкий узел).

## Заметки

- Модель данных (`../data-model.md`) — черновик, подлежит пересмотру после
  принятия OQ-2; там же сироты без владельцев (атака A12) — нужен проход
  "каждая сущность -> модуль".
- Прототипные идеи archmap (`.c4`-файлы в git, MR-правки, `#manual_check`)
  работают только в варианте git-as-truth; если выберем БД-as-truth, от
  наследия archmap останется лишь часть.

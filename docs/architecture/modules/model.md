# `model` — хранит граф связей о системе

Статус: ready for implementation (разблокирован ADR-0003)
Зависит от: reconcile
Используется: resolve, policies, drift, assurance, portal, pr-bot, chat-bot, export

## Назначение

Единое хранилище, где живёт граф системы: узлы — сервисы, базы, очереди, документы — и связи между ними. Граф сохраняется между перезапусками, версионируется (можно посмотреть, как выглядела система на любой коммит) и доступен для запросов. Без этого модуля Archon остаётся генератором картинок. Все остальные модули либо пишут в граф, либо читают из него, ничего не дублируя.

## Что делает

- Хранит узлы и связи. Спецификация структуры графа и Cypher DDL — в `../sample-architecture.md` (раздел 5) и `../data-model.md`.
- Ведёт версии и историю: «что было на коммит X», чем граф в одной версии отличается от другой.
- Даёт единый API для запросов: поиск, выборки, анализ влияния («что сломается, если поменять этот сервис»). Запросы формулируются в стандарте openCypher.
- Даёт постоянные ссылки на любой элемент графа — чтобы из уведомления, отчёта или сообщения бота можно было перейти точно в нужное место.
- Сводит изменения: если человек поправил что-то вручную, следующий автоматический прогон не должен затереть его правку.

Не делает: не извлекает факты из кода (`extract`/`interpret`), не примиряет противоречия (`reconcile`), не склеивает сущности между репозиториями (`resolve`), не проверяет правила (`policies`), не сопоставляет документы с кодом (`drift`), не ведёт проверку человеком (`assurance`).

## Интерфейсы

- **Вход:** согласованные факты из `reconcile`; правки человека через pull/merge request; статусы доверия из `assurance`.
- **Выход:** openCypher API запросов для всех потребителей выше (MCP Server, portal, pr-bot, export).

## Данные и хранилище

Согласно [ADR-0003](../../adr/0003-source-of-truth-and-tenant-isolation.md):
- **СУБД:** PostgreSQL 16 с расширением Apache AGE (`apache/age:PG16_latest`).
- **Мультитенантность:** Строгая изоляция — один тенант = один изолированный граф (`SELECT create_graph('tenant_<id>')`), физически разделенный на уровне отдельных схем PostgreSQL.
- **Стандарт доступа:** Все графовые запросы инкапсулируются в репозитории через openCypher. Прямые PostgreSQL-хаки запрещены для обеспечения прозрачной миграции на Memgraph/Neo4j при масштабировании.
- **Source of Truth:** Граф в базе является каноническим эталоном архитектуры. Git-репозитории клиентов выступают источником фактов (Source of Code).

## Форма деплоя

Сборочная единица **`archon-core-service`** (Kotlin / JVM) согласно [ADR-0007](../../adr/0007-saas-process-topology-and-packaging.md) и [`deployment.md`](../deployment.md). Модуль инкапсулирует слой доступа к данным (DAL) для PostgreSQL 16 + Apache AGE и исполняется внутри процессов бэкенда и воркера Temporal.

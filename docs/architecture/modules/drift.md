# `drift` — рассинхрон документации и кода

Статус: new
Компетенция: RAG, embeddings, документы
Зависит от: model, sources (Confluence/Jira), registry
Используется: assurance, portal, chat-bot (через `assurance`)

## Назначение

Выполняет главную миссию Archon: документация не должна расходиться с кодом.
Сравнивает утверждения из документов с фактами графа и показывает, где доки
врут.

## Что делает

- Индексация Confluence/ADR/спеков: эмбеддинги + реестр "документ -> элемент
  графа".
- Сравнение claims из документов с фактами графа.
- Пишет находки (противоречия) в `assurance` с метрикой дрейфа, а не живёт с
  ними.

Не делает: не владеет жизненным циклом находок — его ведёт `assurance`; не
нормирует сырые документы — получает их из `sources`, но режет и эмбеддит сам
(граница по атаке A10: `sources` отдаёт сырье, потребитель режет).

## Данные

Своя тяжёлая инфраструктура — индекс документов, эмбеддинги, реестр привязок.
Именно она обособила `drift` от `policies` в A3.

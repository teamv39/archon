# Шаблон файла модуля

Копировать в `docs/architecture/modules/<код>-<название>.md`, заполнить,
добавить строку в реестр `README.md`.

Принципы:
- Файл описывает текущее состояние модуля. Споры и обоснования — в ADR,
  открытые вопросы — в `../open-questions.md`, здесь только ссылки.
- Коротко лучше, чем длинно и устаревшее. Пустые секции помечаем `TBD`, не
  выдумываем.
- Объем ~100-200 строк. Растет дальше 200 — выносим детали во вложенный файл.

---

```markdown

- **Выход:** кому, в какой форме.

## Данные

Что модуль хранит у себя, где, в какой модели. Если не хранит — так и пишем.
```

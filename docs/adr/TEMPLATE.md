# Шаблон Architecture Decision Record

Используй этот шаблон для новых ADR. Копируй и заполняй.

```markdown
# NNNN. Название решения

Дата: YYYY-MM-DD

## Статус

[Proposed | Accepted | Deprecated | Superseded by ADR-XXXX]

## Контекст

Какую проблему решаем? Что привело к необходимости принять решение?

## Решение

Что именно делаем?

## Альтернативы

Какие варианты рассматривали? Почему не выбрали их?

### Вариант 1: Название
Описание подхода

**Плюсы:**
- ...

**Минусы:**
- ...

**Почему не выбрали:**
- ...

### Вариант 2: Название
...

## Последствия

Что это решение дает и что усложняет?

### Плюсы
- ...

### Минусы
- ...

### Риски
- ...
- Митигация: ...
```

## Когда создавать ADR

- Выбираешь между несколькими технологиями
- Меняешь архитектурный подход
- Принимаешь решение, которое сложно откатить
- Отказываешься от какого-то подхода в пользу другого

## Когда НЕ нужен ADR

- Мелкие технические решения (выбор библиотеки для парсинга YAML)
- Очевидные решения без альтернатив
- Временные workaround-ы
